# VS Code cookbook

installed prettier extension
installed "Awesome Emacs Keymap" extension

| what | how
| ---- | ---
| change tabs within pane | Ctrl+1, Ctrl+2, etc.
| change panes | Cmd+1, Cmd+2, etc.
| open file referenced in declaration | Cmd-click
| search all files | Cmd+Shift+F
| format section | Cmd+K Cmd+F (with prettier extension)
| format all | Option+Shift+F (with prettier extension)
| quick open files by name | Cmd+P
| create new file | Ctrl+Option+Cmd+N
| toggle sidebar (explorer) | Cmd+B
| show explorer | Shift+Cmd+E
| toggle block comment | Shift+Option+A
| inline Copilot | Cmd+I
| Copilot sidebar | Shift+Cmd+I

also see https://code.visualstudio.com/shortcuts/keyboard-shortcuts-macos.pdf
